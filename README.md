# 价策 AI（PriceScope AI）

面向电商商家的智能定价决策与经营分析 MVP。产品将商家价格、成本、销量、库存与竞品报价统一分析，输出可解释的价格诊断、调价模拟和可视化报告。

## 已实现功能

- 经营驾驶舱与关键指标
- 商品价格健康度分析
- 市场中位价、加权市场价与价格指数
- 利润安全线与经营角色策略
- 商品级 AI 诊断说明
- 调价销量、销售额与毛利模拟
- CSV 商品/竞品数据导入
- 调价清单 CSV 导出
- 可打印的管理层周报
- 浏览器本地数据保存
- 响应式桌面与移动端布局

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
corepack enable
pnpm install
pnpm dev
```

打开终端显示的本地地址。默认开发地址通常为 `http://127.0.0.1:4173`。

## 测试与构建

```bash
pnpm test
pnpm lint
```

`pnpm test` 会运行定价引擎单元测试、TypeScript 检查和生产构建。

## 数据导入

使用 [`examples/商品导入示例.csv`](examples/商品导入示例.csv) 或在产品“数据中心”下载模板。MVP 数据只保存在当前浏览器的 `localStorage`，不会上传到服务器。

## 目录结构

```text
src/
  App.tsx              产品页面与交互
  data/demo.ts         母婴奶粉演示数据
  lib/pricing.mjs      定价诊断与模拟引擎
  styles.css           完整视觉样式
tests/                 定价引擎自动化测试
examples/              CSV 导入样例
docs/                  产品说明文档
```

## 当前版本边界

这是用于产品验证的前端 MVP。竞品报价来自演示数据或 CSV 导入；未直接抓取电商平台，也不会自动修改线上商品价格。接入真实平台、账号权限、服务端数据库和自动调价前，应完成平台授权、数据合规审查与审批机制建设。
