# 价策 AI 产品展示说明

> 面试定位：一个把“多平台价格情报”转化为“可执行定价决策”的商家侧产品。

## 1. 一句话介绍

价策 AI 面向电商运营、品类经理和定价团队，持续汇总国内主流平台的商品报价与优惠条件，核算尽可能接近真实下单的到手价，再结合成本、销量、商品角色与最低毛利要求，输出建议价格、价格拐点、调价风险和可视化经营报告。演示货盘覆盖母婴奶粉、食品饮料、家用电器和个护清洁，并允许通过 CSV“品类”字段继续扩展。

它并不是一个简单的消费者比价工具。消费者比价回答“哪里更便宜”，价策 AI 回答商家更关心的三个问题：

1. 我的商品在市场价格带中处于什么位置？
2. 在不击穿利润的前提下，应该调到多少？
3. 调价后销量、销售额和毛利可能发生什么变化？

## 2. 用户与业务问题

| 用户 | 典型任务 | 原有痛点 |
|---|---|---|
| 电商运营 | 每日跟价与活动定价 | 人工查价慢、活动口径不一致 |
| 品类经理 | 管理不同角色商品 | 一刀切降价，缺少商品分层 |
| 定价分析师 | 建模与复盘 | 数据散落，结论难落地 |
| 经营负责人 | 判断价格竞争力 | 缺少清晰、可汇报的经营视图 |

## 3. 产品设计逻辑

产品按照“数据可信 → 判断可解释 → 决策可试验 → 结果可复盘”设计。

```text
价格采集
  ↓ 公开价 + 账户授权态 + 商家优惠策略
真实到手价核算
  ↓ 优惠互斥/叠加、门槛、运费、账户口径
商品标准化与同款匹配
  ↓ 品牌 + 系列 + 段位 + 规格 + 置信度
市场价格带
  ↓ 中位价、加权价、价格指数
价格拐点分析
  ↓ 峰值/谷值、销量响应、市场价差、可信度
经营约束
  ↓ 成本、最低毛利率、库存、商品角色
策略建议
  ↓ 进攻 / 平衡 / 保守价格区间
调价实验
  ↓ 预计销量、销售额、毛利、风险
报告复盘
```

这里最重要的产品取舍是：不直接给出一个“神奇价格”，而是给出价格区间、依据、利润边界和实验建议，让运营人员保留最终决策权。

## 4. 核心功能与效果展示

### 4.1 经营驾驶舱

![经营驾驶舱](assets/dashboard.png)

第一屏回答经营负责人最关心的四件事：整体销售规模、增量机会、毛利表现和竞品覆盖率。价格竞争力矩阵把价格指数、销量和毛利空间放在同一张图中，用于发现优先处理的商品。

### 4.2 价格采集中心

采集中心采用两种模式：

- 演示快照：用于面试和无平台密钥环境，明确标识为 DEMO，保证展示稳定。
- 按品牌选品：以商家货盘为基准，按品牌、系列、规格和关键词筛选 SKU，再选择京东、天猫、拼多多等目标平台及公开价/条件可实现价/已持券价口径。系统生成“SKU × 平台”任务，高置信度同款直接进入采集，未匹配项进入人工复核。
- 本地采集服务：接收用户提供的公开商品页，限制京东、天猫/淘宝、拼多多、苏宁、唯品会 HTTPS 域名，逐个限速请求，检查 robots.txt，提取 JSON-LD、价格 Meta 或公开页面数据。

真实商业部署优先对接平台开放 API，可参考[京东 API 调用指南](https://help.jd.com/oapihelp/question-460.html)、[京东商品售卖价接口](https://opendoc.jd.com/iopv2/iopv2/%E4%BB%B7%E6%A0%BC/%E6%9F%A5%E8%AF%A2%E5%95%86%E5%93%81%E5%94%AE%E5%8D%96%E4%BB%B7.html)和[淘宝开放平台商品 API](https://developer.alibaba.com/docs/api.htm?apiId=6)。系统不绕过登录、验证码或访问限制；动态页面无法合法获得价格时会返回失败，并建议改用开放 API 或 CSV。

### 4.3 优惠策略中心

优惠策略中心把划线价、公开售价、条件可实现价和已持券实际价分层展示。用户只需在对应平台官方页面完成一次登录，授权状态在本机持续复用；系统不收集密码。优惠领取提供“仅识别、逐次确认、规则授权”三档，默认逐次确认，兼顾低操作成本和价格真实性。

商家还可以提交官方优惠链接。系统校验 HTTPS、平台域名、活动标识、门槛、有效期和可叠加关系，再核算最优合法组合。会员、新客、地区或账户定向价格不会混入公开市场中位数。完整逻辑见[真实到手价与优惠工作流](真实到手价与优惠工作流.md)。

### 4.4 商品级价格诊断

![价格诊断](assets/diagnosis.png)

系统展示当前到手价、市场中位价、价格指数、毛利率、诊断状态和建议区间。运营可打开商品详情查看各平台报价、数据权重、匹配可信度与 AI 判断依据。

### 4.5 调价模拟器

![调价模拟器](assets/simulator.png)

运营在执行前选择进攻、平衡或保守价格。模型用价格弹性估算销量变化，同时计算销售额、毛利额和毛利率。如果价格低于利润安全线，界面会直接提示风险。

### 4.6 管理层报告

![报告中心](assets/reports.png)

报告把商品级明细聚合为经营结论、重点优化商品和增量机会，可打印为 PDF，也可导出调价清单供运营执行。

报告中心将信息分为管理摘要、品牌跨平台比价和运营执行清单。品牌矩阵支持品类、品牌和 Top 3/5/10 筛选，一行一个标准 SKU、一个平台一列，并用热力颜色标出最低价；平台价格指数和 SKU 价差条形图用于快速定位系统性高价渠道和异常商品。矩阵支持 CSV 导出。

## 5. 定价策略体系

### 5.1 核心指标

- 市场中位价：同款有效报价的中位数，降低极端活动价干扰。
- 加权市场价：按平台可信度和样本权重计算的市场参考价。
- 价格指数：`本店到手价 ÷ 市场中位价 × 100`。
- 利润底价：`商品成本 ÷ (1 - 最低毛利率)`。
- 匹配可信度：综合品牌、系列、段位、规格和有效报价数量。

### 5.2 商品角色策略

| 商品角色 | 经营目标 | 定价动作 | 核心观察指标 |
|---|---|---|---|
| 引流型 | 获取访问与新客 | 靠近市场低位，但不突破利润底价 | 访客成本、连带率、新客数 |
| 转化型 | 提升下单效率 | 保持市场中位价附近，小范围实验 | 转化率、销量弹性、销售额 |
| 利润型 | 贡献毛利 | 允许合理溢价，减少直接折扣 | 毛利额、折扣深度、复购率 |
| 形象型 | 强化品牌定位 | 跟随标杆，避免频繁价格波动 | 价格稳定性、品牌搜索量 |

### 5.3 策略护栏

1. 匹配可信度低于阈值时不给自动调价，只提示人工审核。
2. 建议价格不得低于利润底价。
3. 大幅调价拆成 7 天小流量实验，设置销量和毛利双重停止条件。
4. 促销券、满减和赠品应折算为统一到手价，再进入比较。
5. 自动化只负责建议与告警，当前版本不直接修改平台售价。

## 6. 技术架构

```text
React + TypeScript 前端
├─ 驾驶舱 / 诊断 / 模拟 / 报告
├─ 浏览器本地数据与 CSV 导入导出
└─ 采集中心（Demo / Local 双模式）

Node.js 本地采集服务
├─ 平台域名白名单
├─ robots.txt 检查与串行限速
├─ JSON-LD / Meta / 页面数据解析
└─ 结构化采集结果与错误原因

Python 真实到手价服务
├─ 优惠链接平台白名单与活动识别
├─ 满减门槛、互斥组与最优组合核算
├─ 本机授权状态登记（不接收密码）
└─ 受控 Agent 修复提案与脱敏护栏

定价算法层
├─ 中位数与加权市场价
├─ 价格指数与利润底价
├─ 商品角色建议区间
└─ 价格弹性模拟
```

技术选型强调可演示、可测试和可扩展：前端使用 React/TypeScript；采集器只依赖 Node.js 内置能力，便于审查安全边界；核心算法使用纯函数，方便单元测试和后续替换为模型服务。

## 7. 测试设计

- 定价算法：中位数、加权价、价格状态、利润底价、弹性模拟和组合汇总。
- 真实到手价：优惠门槛、互斥组、会员价隔离、运费与最优组合。
- 安全边界：优惠链接仿冒域名、本机会话登记、快照脱敏与 Agent 修改范围。
- 采集解析：平台域名识别、JSON-LD 价格、Meta 价格和 robots 规则。
- 工程质量：ESLint、TypeScript 和生产构建。
- 产品交互：桌面/移动布局、导航、商品详情、风险提示、CSV 导入和报告页。

## 8. 我会如何在面试中讲这个项目

建议用 3 分钟完成：

1. 30 秒：商家不是缺少价格，而是缺少“可执行且不伤利润”的定价决策。
2. 45 秒：展示数据链路——采集、匹配、价格带、利润约束、策略建议。
3. 60 秒：依次打开驾驶舱、价格诊断、调价模拟器和报告中心。
4. 30 秒：强调采集的双模式设计和合规边界，避免把反爬绕过包装成能力。
5. 15 秒：说明下一阶段将接入官方 API、历史数据库、实验平台和审批流。

## 9. 后续路线图

| 阶段 | 能力 |
|---|---|
| MVP（当前） | 演示数据、公开页采集、真实到手价引擎、优惠链接识别、诊断、模拟、报告 |

## 10. 产品边界

当前版本是决策支持工具，不承诺页面采集在所有平台长期可用，也不自动修改商家价格。生产环境需要商家自己的平台授权、服务器与数据库，并持续遵守各平台开放规则和数据使用政策。
